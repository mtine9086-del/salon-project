# Catalogue images

Upload approved hairstyle and beard reference images into this folder using GitHub's website.

Suggested filenames:
- low-fade.jpg
- textured-crop.jpg
- classic-taper.jpg
- pompadour.jpg
- short-stubble.jpg
- full-beard.jpg
- goatee.jpg
- beard-fade.jpg

Use optimized JPG or WebP images when possible. Replace the temporary photo URLs in `../style.css` with paths such as `images/low-fade.jpg`.
