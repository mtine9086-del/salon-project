# Salon Project — Curated Hairstyle Assets

This folder contains 12 recovered, valid 1024×1024 WebP catalogue images from the uploaded archive.

## Included
- `burst-fade-01.webp`, `burst-fade-02.webp`
- `curly-top-fade.webp`
- `shadow-fade-01.webp`, `shadow-fade-02.webp`
- `low-skin-fade-01.webp`, `low-skin-fade-02.webp`
- `high-top-fade.webp`
- `mid-skin-fade.webp`
- `comb-over-fade-01.webp`, `comb-over-fade-02.webp`
- `high-skin-fade.webp`

## Duplicate cleanup
- Removed one exact duplicate of the High Top Fade image.
- Removed one exact duplicate of the Shadow Fade image.
- The two Low Skin Fade, Burst Fade, and Comb Over Fade images are visually different variants, so both were retained.

## Important limitation
The uploaded archive was damaged/truncated. 15 entries could be identified, 14 images were fully recoverable and readable, and one image was incomplete/unreadable. This pack includes 12 unique valid images after removing exact duplicates. The recovered images cover only 8 hairstyle types; they do not yet cover all 18 styles in the project list.

## Integration note
These are complete four-view catalogue posters with text already embedded, not isolated single hairstyle photos. They can be used as poster-style gallery images. If the project cards are designed to show a single haircut photo, crop/prepare separate image assets before replacing those cards.
